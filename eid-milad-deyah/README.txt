Eid Milad, Deyah! - birthday website

Open index.html in a browser (or use the Live Server extension in VS Code).
Needs internet for the Google Fonts (Baloo 2, Nunito, Caveat).

Edit these in script.js:
- REASONS      : the 5 lantern messages (page 2)
- GIFT_TITLE, GIFT_DESC, GIFT_DUA : the virtual gift (page 3)
- LETTER       : the notebook letter, each [ ... ] is one page (page 4)

Colors and fonts live at the top of style.css (the :root variables).
